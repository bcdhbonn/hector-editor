# 🏛️ HECTOR-Editor – Wiki & User Guide

Welcome to the **HECTOR-Editor** documentation. This wiki is a detailed guide on installing, using, and managing semantic SKOS vocabularies with the HECTOR-Editor application.

For ease of navigation, the documentation is split into separate subpages:

## 📖 Wiki Table of Contents

* **[1. Installation & Setup](wiki/Installation.md)**
  System requirements, package installation, and how to run or package the app.
* **[2. User Interface Guide](wiki/User-Interface.md)**
  Layout walkthrough (Workspace Panel, Treeview, Editor Panel, and Console).
* **[3. Core Workflows](wiki/Workflows.md)**
  Creating, importing, and loading schemas, concept management (Add/Edit/Delete), and setting hierarchies.
* **[4. Authority Matching](wiki/Authority-Matching.md)**
  Asynchronously querying and linking external authority sources (Wikidata, Getty AAT, GND).
* **[5. Data Quality & Integrity Checks](wiki/Data-Quality.md)**
  Symmetrical broader/narrower sync, repairing missing labels, and tracing orphan concepts.

## 🤝 Project Context & Funding
This tool was developed as part of the consortium **NFDI4Objects** (National Research Data Infrastructure for Objects of Material Cultural Heritage) within *Trail 1: Archaeological Remote Sensing in the Roman Rhineland*.

NFDI4Objects is funded by the German Research Foundation (DFG) - Project number 441958489.
