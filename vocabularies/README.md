# BCDH SKOS Vocabularies Collection

This directory contains semantic SKOS vocabularies managed and developed by the BCDH team. Each vocabulary is organized into its own dedicated sub-directory with its own documentation.

---

## 📂 Available Vocabularies

### 1. **[HECTOR Epoch SKOS Vocabulary](hector_epochs/README.md)**
* **Directory:** `hector_epochs/`
* **File:** `hector_epochs/HECTOR_Epoch.ttl`
* **Description:** An integrated archaeological epoch vocabulary comprising core baseline epochs, Roman emperors, medieval dynasties and rulers (HRR, England, France, Spain, Italy), Ancient Egypt dynasties/pharaohs, and a fine-grained chronological grid.
* **Namespace:** `http://vocabs.bcdh.uni-bonn.de/hector_epochs/`
